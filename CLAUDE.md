# CLAUDE.md — Riktlinjer för SurveyDrone / WashDrone

## Grundregel: Aldrig gissa eller anta

**All information på webbplatsen ska vara verifierad och korrekt.** Följande regler gäller utan undantag:

- **Gissa aldrig** fakta om utrustning, drönare, kameror eller sensorer. Ange bara modeller och specifikationer som WashDrone/SurveyDrone faktiskt äger och använder.
- **Anta aldrig** vilka certifieringar, tillstånd eller behörigheter piloterna har. Ange bara certifieringar som företaget faktiskt innehar och kan verifiera.
- **Hitta aldrig på** siffror, procent, priser eller prestandamått. Alla numeriska påståenden (t.ex. "upp till 50% billigare", "80% snabbare") måste kunna styrkas med fakta eller tas bort.
- **Fabricera aldrig** kundcase, citat, namn eller företagsnamn. Alla testimonials och kundberättelser ska vara från riktiga kunder med deras medgivande.
- **Påstå aldrig** att företaget erbjuder tjänster eller har kapacitet som inte är bekräftad (t.ex. "hela Sverige", "ex-klassade zoner").
- **Anta aldrig** regulatoriska krav eller tillstånd. Referera bara till specifika regelverk (EASA, Transportstyrelsen, PDRA) om det är bekräftat att företaget uppfyller dessa.

### Vid osäkerhet

Om en faktauppgift inte kan verifieras:
1. Fråga ägaren/uppdragsgivaren först
2. Använd mjukare formuleringar tills fakta bekräftas (t.ex. "kontakta oss för detaljer" istället för specifika siffror)
3. Ta bort påståendet helt om det inte kan styrkas

### Kontaktuppgifter och företagsinfo

- Företagets juridiska namn, organisationsnummer, adress och kontaktuppgifter ska hämtas direkt från ägaren
- Domännamn och e-postadresser ska vara verifierade
- Telefonnummer ska vara verkliga (inte platshållare)

## Projektet

- Next.js-sajt (App Router) med TypeScript och Tailwind CSS
- Innehåller tjänstesidor för drönarinspektioner: tak, fasad, solceller, industri, byggdokumentation
- Målgrupp: B2B-kunder i Sverige (fastighetsförvaltare, byggföretag, energibolag, industri)
